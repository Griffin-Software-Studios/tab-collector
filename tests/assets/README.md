# Test Assets

This folder stores repo-local validation artifacts.

Use it for:

- screenshots captured during manual or assisted Edge validation
- other proof artifacts that should remain versioned in the repository

Do not treat these files as packaged extension assets. The `tests/` tree is
excluded from release packaging.

Current screenshot baselines generated by `npm run evidence:edge`:

- `screenshots/collector-page-edge.png` (desktop collector)
- `screenshots/collector-page-tablet-edge.png` (tablet collector)
- `screenshots/collector-page-mobile-edge.png` (mobile collector)
- `screenshots/popup-page-edge.png` (popup)
- `screenshots/options-page-edge.png` (options)
